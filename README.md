# 📊 Stock Market Analysis

This project analyzes stock market data using Python.  
It calculates stock returns and volatility and compares the performance of multiple stocks.
---
## 📌 Features
- Simulated stock market dataset (2020–2025)
- Calculation of daily returns
- Volatility analysis
- Comparison of multiple stocks
---
## 🧰 Tools
- Python
- Pandas
- Matplotlib
- NumPy
---
## 📈 Data Source
⚠️ This project uses **synthetic (simulated) financial data** generated to mimic real market behavior.  
No real market data (e.g., Yahoo Finance) is used.
